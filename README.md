## 🎨 Overview

This project showcases a **pure CSS-based parallax effect** —  
**no JavaScript, no libraries**, just clean and simple HTML + CSS.

The page uses layered backgrounds and controlled scrolling speeds  
to create a **natural depth illusion** when the user scrolls.

---

## 🌟 Features (Only what the project actually includes)

- ✨ **Smooth parallax scrolling effect**  
- 🎨 **Clean and minimal UI**  
- ⚡ **Lightweight (HTML + CSS only)**  
- 📱 **Works on all modern browsers**  
- 🔍 **Easy to edit & customize**

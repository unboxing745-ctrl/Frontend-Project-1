# 🌄 Parallax Effect Website

A simple and creative **frontend project** built using **only HTML and CSS**.  
It uses the **parallax scrolling effect** to create smooth, eye-catching motion and depth as you scroll down the page.  

---

## 🎨 Features

- ✨ Smooth parallax scrolling  
- 💻 100% HTML & CSS (no JavaScript)  
- 🧭 Responsive and clean layout  
- 🌈 Lightweight and fast loading  

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**

## 🌌 About the Project

**Parallax Effect** is a **pure HTML and CSS** project that adds *depth, motion, and beauty* to a webpage.  
It creates an illusion of **movement and distance** by making background layers scroll at different speeds —  
giving a smooth, immersive 3D experience 🎢.

> 💫 “No code that runs — just design that moves.”

---

## 🌈 Features

- 🏞️ **Smooth Parallax Scrolling** — powered entirely by CSS  
- 📱 **Responsive Layout** — looks great on any screen  
- 🎨 **Visually Stunning Layers** — depth and motion made simple  
- ⚡ **Lightweight & Fast** — no scripts, no dependencies  
- 🧠 **Perfect for Learning** — great example of advanced CSS use
